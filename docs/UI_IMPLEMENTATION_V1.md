# UI IMPLEMENTATION V1

تم تنفيذ الهيكل الأول لواجهة أثري باستخدام Next.js App Router وTypeScript.

## الصفحات
- `/login`
- `/`
- `/evidence`
- `/evidence/new`
- `/evidence/[id]`
- `/portfolio`
- `/account`

## الهدف من هذه الدفعة
تثبيت تجربة الاستخدام والشكل العام قبل ربط:
- Firebase Authentication
- Firestore
- Cloud Storage
- AI backend

- البيانات الحالية تجريبية ومحلية فقط.
- أزرار الاعتماد والرفع لا تحفظ بيانات بعد.
- الواجهة RTL وMobile-first.
- لا توجد مفاتيح أو أسرار في الكود.
