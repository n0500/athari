# SECURITY & PRIVACY

أثري يتعامل مع ملفات مهنية قد تحتوي بيانات شخصية أو مدرسية، لذلك:

1. لا ترفع أسرارًا أو مفاتيح API إلى GitHub.
2. لا ترسل ملفًا إلى مزود AI قبل التحقق من صلاحية المستخدم.
3. لا تجعل ملفات الشواهد عامة افتراضيًا.
4. افصل صلاحيات المعلمة عن صلاحيات المراجعة والإدارة.
5. احتفظ بسجل للإجراءات المهمة مثل الاعتماد والحذف والتعديل.
6. أي رابط مشاركة يجب أن يكون مقصودًا وقابلًا للإلغاء.
7. لا تستخدم بيانات الشواهد في عينات تجريبية عامة.
8. ضع حدودًا لنوع وحجم الملفات.
9. لا تثق في اسم الملف أو نوعه المعلن من العميل فقط.
10. قبل الإنتاج، راجع قواعد التخزين وقاعدة البيانات واختبر الوصول غير المصرح به.
