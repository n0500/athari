# UI V1 — أثري

## مبدأ التصميم
واجهة عربية RTL، Mobile-first، هادئة، واضحة، بدون ازدحام. كل شاشة لها إجراء رئيسي واحد.

## التنقل الرئيسي

على الجوال:
- الرئيسية
- ملفي
- الشواهد
- الحساب

زر ثابت/واضح:
**+ إضافة شاهد**

## 1. شاشة الدخول
- شعار أثري
- جملة قصيرة: "حوّلي شواهدك إلى ملف أداء منظم وموثق."
- تسجيل الدخول
- لا تفاصيل تقنية ولا تسويق طويل.

## 2. الرئيسية
تحتوي فقط على:
- ترحيب بالمعلمة.
- بطاقة "ملفي الحالي".
- عدد الشواهد المعتمدة.
- عدد الشواهد التي تحتاج مراجعة.
- زر كبير: `إضافة شاهد`.
- قسم صغير: `يحتاج انتباهك`.

لا تعرض رسومًا كثيرة في V1.

## 3. إضافة شاهد
الخطوة الأولى:
- رفع صورة أو PDF أو ملف مدعوم.
- توضيح بسيط: "سنقرأ الشاهد ونقترح التصنيف والصياغة. لن يضاف شيء قبل موافقتك."

بعد الرفع:
- شاشة معالجة واضحة.
- اسم الملف.
- حالة التحليل.
- إمكانية الخروج والعودة للشاهد لاحقًا.

## 4. مراجعة الشاهد — أهم شاشة

أعلى الشاشة:
- معاينة الأصل / فتح الأصل.

ثم بطاقات مرتبة:
1. `ما فهمه أثري من الشاهد`
   - حقائق مستخرجة فقط.
2. `التصنيف المقترح`
   - العنصر الأول + سبب قصير.
   - بديل واحد عند الحاجة.
3. `الصياغة المقترحة`
   - العنوان.
   - وصف التنفيذ.
   - الأثر.
4. `معلومة ناقصة`
   - تظهر فقط عند الحاجة.
   - سؤال واحد واضح.

أسفل الشاشة:
- زر رئيسي: `اعتماد وإضافة لملفي`
- زر ثانوي: `تعديل`
- خيار نصي: `تغيير التصنيف`

## 5. الشواهد
Tabs بسيطة:
- تحتاج مراجعة
- معتمدة
- الكل

كل بطاقة تعرض:
- العنوان.
- العنصر.
- الحالة.
- تاريخ الإضافة.
ولا تعرض تفاصيل كثيرة.

## 6. ملفي
يعرض عناصر الأداء بالترتيب الرسمي.
لكل عنصر:
- اسم العنصر.
- عدد الشواهد المعتمدة.
- الشواهد التابعة له.
- حالة تغطية وصفية فقط في V1، بدون درجة أداء آلية.

## 7. عرض الملف
وضع قراءة نظيف يصلح للمشاركة/التصدير لاحقًا:
- بيانات المعلمة.
- إطار الأداء والسنة.
- العناصر.
- الشواهد المعتمدة فقط.
- فتح الأصل عند الصلاحية.

## حالات UX الإلزامية
- Upload progress.
- Analysis in progress.
- Needs info.
- Ready for review.
- AI failed.
- File unsupported.
- Offline/retry.
- Unauthorized.

## اللغة
استخدم عبارات بشرية قصيرة:
- "جاري قراءة الشاهد"
- "وجدت معلومة تحتاج تأكيدك"
- "هذا اقتراح ويمكنك تعديله"
- "تمت الإضافة لملفك"

تجنب:
- confidence score للمستخدمة.
- مصطلحات تقنية مثل OCR / JSON / model.
- عبارات توحي أن AI اتخذ القرار بدل المعلمة.
