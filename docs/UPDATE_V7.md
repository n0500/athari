# تحديث V7 — توحيد اللغة ومشاركة ملف الأداء وسلامة الرفع

## اللغة والمصطلحات
- لغة رسمية موجزة، وحُذفت العبارات الإنشائية: «الفهرس الذكي»، «ملفك المهني الآن»، «موثق ومحفوظ».
- عناوين الصفحات:
  | الصفحة | العنوان | الوصف |
  |---|---|---|
  | `/` | ملف الأداء المهني | ملخص الشواهد وتغطية عناصر التقييم. |
  | `/evidence` | الشواهد | استعراض الشواهد وإدارتها. |
  | `/portfolio` | ملف الأداء المهني | عناصر التقييم والشواهد المرتبطة بها. |
  | `/element` | عنصر التقييم | بيانات العنصر والشواهد المرتبطة به. |
  | `/evidence/new` | إضافة شاهد | إضافة ملفات للإنجاز نفسه. |
  | `/evidence/review` | مراجعة الشاهد | مراجعة البيانات والتصنيف قبل الاعتماد. |
  | `/account` | الحساب | إدارة الحساب وخيارات المشاركة. |
  | `/preview` | معاينة ملف الأداء | معاينة الملف قبل الطباعة أو المشاركة. |
- «عناصر التقييم / عنصر التقييم» في كل الصفحات. صفحة العنصر تعرض «الفئة». مصطلح «التصنيف الأساسي» في شاشة المراجعة فقط.
- «مشاركة ملف الأداء» بدل «رابط المديرة» في كل الواجهات.

## مشاركة ملف الأداء
- زر «مشاركة ملف الأداء» أعلى صفحة ملف الأداء، بجانب «معاينة / طباعة». يفتح لوحة: إنشاء الرابط، نسخه، تحديث المشاركة، إيقافها.
- صفحة الحساب: حالة Google Drive ونص الخصوصية، ورابط ثانوي `/portfolio?share=1` يفتح اللوحة.
- نص الخصوصية المعتمد: «يعرض الرابط الشواهد المعتمدة فقط دون الوصول إلى بقية ملفاتك.»

## رموز المعلومات ⓘ (`src/components/InfoTip.tsx`)
رفع الشاهد، الاعتماد، المشاركة، الأرشفة. لا ⓘ للأزرار الواضحة.

## سلامة البيانات
1. **تحديث المشاركة:** تُحفظ نسخة المشاركة أولًا، ثم تُسحب صلاحيات الملفات التي خرجت منها. إن فشل الحفظ أو منح الصلاحيات، تُلغى الصلاحيات التي أُضيفت في المحاولة نفسها. الصلاحيات التي تعذّر سحبها تبقى مسجلة ويُعاد سحبها في التحديث التالي.
2. **مزامنة المشاركة عند الأرشفة أو الحذف أو تنظيف المكرر** (`src/lib/shareSync.ts`): يُزال الشاهد من نسخة المشاركة فورًا، وتُسحب الصلاحية عن كل ملف لم يعد مستخدمًا في أي شاهد مشارك.
3. **استكمال الرفع:** لكل مرفق `attachmentId` فريد، ويُسجل كل ملف في Firestore فور اكتمال رفعه. عند إعادة المحاولة تُطابق الملفات بالاسم والحجم والبصمة معًا، ويُستخدم كل سجل مرة واحدة، فلا يختلط ملفان لهما المحتوى نفسه.

## الطباعة
`/preview` يطبع ملخص التغطية، ثم كل عنصر وتحته شواهده فقط.

## عدد العناصر
يُحسب من `OFFICIAL_TEACHER_FRAMEWORK_V2.length` في كل الواجهات.
